Download the file ending in **Setup.exe** below and double-click it to install. No
administrator password is needed. It installs over any earlier version.

## Real room, not just a bigger scale

Version 1.1.0 let you make the box wider in metres, and that was the wrong answer. It
stretches the same cells over more ground — a zoom control dressed up as more space.

**Physics → How much sandbox → Room** is the real one: how many cells across, up to 160.
The simulation is a grid of cells, so room is measured in cells and nothing else adds
any. The old metres slider is still there, relabelled **Scale**, and now says what it
actually does — how much real space those cells stand for, which changes how heavy and
fast everything looks.

## How much material

**How much material** sets how many specks can exist at once, up to 8.4 million, with
the graphics memory cost shown beside it as you drag.

It does not go to unlimited, and it can't. Every speck is followed around by twelve
textures, so one costs 192 bytes of graphics memory, and the pool is a texture with a
fixed size. 8.4 million is about 1.6 GB, which is as far as it goes without asking for
trouble.

Room and material are rebuilt when changed, so the sandbox is emptied.

## Small amounts of material are visible now

A droplet, or the first dab of a brush, could be drawn as nothing at all. The fields are
blurred before the light is traced through them, which spreads a small amount thin, and
anything below half fill was treated as empty space — which a few dozen specks never
reach anywhere.

**Quality → How little counts as something** is that threshold, and its default is much
lower. Small things show up. Raise it if you would rather have tighter surfaces.

## A second, much faster renderer

**Quality → Draw with → Specks** draws every speck once as a little sphere and lets the
graphics card sort out what is in front, instead of following light through the
material. No shadows, no reflections, nothing seen through water — and a fraction of the
cost. Good for building something large, or on a machine that struggles with the tracer.

**Traced rays** is still the default and still where the picture comes from.
