Download the file ending in **Setup.exe** below and double-click it to install. No
administrator password is needed. It installs over any earlier version.

## The sandbox can be made bigger

Until now it was 2.56 metres across and nothing could change that. A quality preset
counts cells, not metres, so picking Ultra gave you finer cells in the same small box
rather than more room.

**Settings (Tab) → Physics → The box → How big it is** now runs from half a metre to
twenty, and takes effect while it runs — nothing is rebuilt and nothing you have made is
lost. The same cells spread over more ground, so a large world is a coarser one.

For more room *at the same detail*, there are two new presets under **Quality**: **Huge**
and **Enormous**, 96 and 128 cells a side. Enormous is about eight times the work of
Medium, so it wants a reasonable graphics card.

Size and detail are separate now: the slider decides how much world the cells cover, the
preset decides how many cells there are.

## The walls can be taken away

**Physics → The box → Walls**:

- **Closed box** — as it was.
- **Open sides** — the floor stays, but anything reaching an edge pours away.
- **No box at all** — the floor goes too, and everything falls for ever.

Water poured near an edge now runs off it. The dam and volcano scenes are worth
revisiting with the sides open.

One honest limit: material that leaves is gone for good. There is no simulation outside
the box to carry it on — it is a fixed grid of cells and there is nowhere else for the
maths to happen — so this is the edge no longer turning things back, rather than the
world continuing past it. Which is exactly what pouring something off the edge of a
table looks like, and it frees the speck to be used again.

The startup crash fix, the detail that matches itself to your computer, and the recovery
from a graphics driver reset.
