Download the file ending in **Setup.exe** below and double-click it to install. No
administrator password is needed.

## Fixes a crash on startup

Version 1.0.0 could open to a black window and then close itself with "the sandbox
stopped unexpectedly". Opening the plain HTML file could take Chrome or Edge down
with it. This release fixes that.

The sandbox was committing to a full-detail frame before it knew anything about the
computer it was running on. Where that frame took more than about two seconds,
Windows decided the graphics driver had hung and reset it, and everything drawing
through that driver died with it.

**It now starts small and works its way up.** The first frame is deliberately cheap;
the sandbox only asks for more once it has watched a few frames go by quickly, and
gives detail back at the first sign of trouble. A quick graphics card reaches full
detail in well under a second. A slower one settles wherever it can actually keep up,
instead of crashing. On the slowest machine available for testing, the opening frame
went from 3.4 seconds to 1.3.

**If something does go wrong, it recovers.** A graphics driver reset is now caught,
explained and started again with less detail rather than ending the run — and the next
time you open it, it remembers and starts small, so you get a working sandbox instead
of the same black window every time. The Quality tab tells you when that has happened
and lets you ask for more.

Also fixed: three faults capable of causing this on their own — undefined-behaviour
texture sampling inside the ray-marching loops, tracer loop limits far larger than
anything the maths needs (which a graphics driver has to compile in full), and a
restored drawing context that had lost the floating-point support everything depends
on.

## Everything else

Nothing about the physics or the picture has changed. Quality presets are now a
ceiling on how hard the sandbox will work rather than a fixed setting, and the Quality
tab has a new "Match the speed of this computer" switch — on by default — that you can
turn off to set everything by hand.
