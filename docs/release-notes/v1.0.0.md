First release.

**Windows:** download **`Powder-Toy-3D-Setup-1.0.0.exe`** below and double-click it. No
administrator password is needed — it installs for your account only, adds a Desktop and
Start menu icon, and can be removed from the Start menu. If Windows says *"Windows
protected your PC"*, click **More info** then **Run anyway**; that appears only because the
installer isn't signed by a large software company.

**Anything else:** download **`Powder Toy 3D.html`** from the source tree and open it in
Chrome, Edge, Firefox or Safari. It is the same app — the installer just wraps it in its own
window so it behaves like a normal program.

### What's in it

- Sixteen materials with real densities, viscosities, surface tensions and melting points:
  water, oil, honey, lava, mercury, sand, snow, ash, stone, ice, steel, glass, wood, steam,
  smoke and fire.
- Nine scenes to start from, plus an empty box.
- Five tools — draw, erase, drag, push, heat — and a camera you can orbit, pan and zoom.
- Every solver and lighting number exposed as a slider, and a **Quality → Show** menu that
  swaps the finished picture for what the solver is thinking: temperature, speed, pressure,
  surface normals, how much sunlight reaches each point.

### If it runs slowly

Open the settings with **Tab**, go to **Quality**, and pick the **Low** preset; the render
resolution slider below it is the other dial that matters. The sandbox also drops its own
resolution automatically if it falls below 24 frames a second.

If it will not start at all, your graphics driver may be out of date or blocked — try Windows
Update. Failing that, the Start menu has a **Powder Toy 3D (without the graphics card)**
shortcut, which always works but is many times slower.

`docs/PHYSICS.md` explains what is being computed, and where the model departs from reality.
