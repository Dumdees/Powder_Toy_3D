## Fixes the black window on startup

Versions 1.0.0 and 1.0.1 could open to a black window that turned white and took the
program down with it, on machines with graphics cards that are not short of anything.
This fixes the actual cause.

On Windows, every browser reaches the graphics card through a translation layer that
turns the sandbox's shaders into Direct3D's own language and hands them to Direct3D's
compiler. That compiler expands loops whose length it can work out in advance — and the
ray tracer's loops had their lengths written into the source. Expanded, a 256-step
march containing texture reads and a second loop of its own becomes enormous, and the
caustics shader ran two of those inside a third loop, so the compiler made four copies
of all of it before it started. Every loop now takes its length at drawing time, so
there is nothing to expand.

Nothing about the picture has changed: the same numbers arrive by a different route.

**Why it took three attempts.** The build's own test forced software rendering, because
the machine that builds these has no graphics card. Software rendering shares none of
that translation or Direct3D's compiler, so the one path every Windows machine actually
takes was the one path never tested, and a shader that took that compiler apart passed
every build cleanly. The test now runs both ways, and fails if the ordinary run quietly
falls back to software.

## A startup that goes wrong now says so

If setting up the graphics goes badly, the sandbox has drawn nothing yet, so there was
nothing to see but a black rectangle. The window title now reports progress — "preparing
the picture (21 of 29)" — which names the exact point it stopped. Shaders are also
prepared together rather than one at a time, which lets a graphics driver use every
thread it has instead of one.

## Also in this release

From 1.0.1, kept and still worth having: the sandbox starts on modest settings and works
up to what your machine can comfortably manage, a driver reset is caught and recovered
from rather than ending the run, and the Quality tab has a "Match the speed of this
computer" switch you can turn off to set everything by hand.
